# 04 | Credit Data & Analytics: Portfolio SQL and PD Model

Bank-wide credit analytics for Prairie Lantern Bank (the bank from Packages 01 and 02): a relational loan database, a library of portfolio SQL queries, and a probability of default model validated out of time and used to estimate expected loss.

> **Synthetic data.** The database is generated by [`data/generate_data.py`](data/generate_data.py) from a known process, so results show the workflow rather than real-world default behavior. No real customer or employer data is used.

![Expected loss by industry](figures/expected_loss_by_industry.png)

## At a glance

| | |
|---|---|
| Database | 1,500 borrowers, 2,399 loans, 15 quarters of snapshots (2023 to 2026), 175 defaulted loans |
| Current book | $2.40B outstanding, $3.66B commitments |
| SQL library | 13 business queries using CTEs, window functions (RANK, LAG, running totals), pivots, and event windows |
| PD model | Logistic regression scorecard; out-of-time AUC 0.77 vs. 0.71 for officer grades |
| Expected loss | $22.1MM (0.90% of exposure); office CRE is 9% of exposure but 46% of expected loss |

## Database schema

```
borrowers ──< loans ──< quarterly_snapshots     (balance, risk grade, days past due, nonaccrual, charge-offs)
    │           ├──< covenant_tests             (annual DSCR, leverage, LTV tests)
    │           └──  defaults                   (EAD, recovery, loss, LGD)
    └──< financials                             (annual revenue, EBITDA, DSCR, leverage, current ratio, LTV)
pd_scores                                       (written back by the notebook; used by query 13)
```

## SQL query library

| # | Business question | Techniques |
|---|---|---|
| 01 | What does the book look like by sector and industry? | Joins, `SUM() OVER ()` for share of total |
| 02 | Who are the 20 largest relationships? How concentrated is the book? | `RANK()`, running total |
| 03 | How has delinquency trended each quarter? | `CASE` buckets, conditional aggregation |
| 04 | How did risk grades migrate over 12 months? | Self-join across dates, pivot |
| 05 | How often do loans roll into worse delinquency? | `LAG()` over partitions, transition matrix |
| 06 | Which origination years perform worst? | Vintage cohorts, `LEFT JOIN` to events |
| 07 | Do the bank's grades rank-order default risk? | Annual cohorts, 12-month event window with `EXISTS` |
| 08 | How much do we lose given default, by collateral? | Exposure-weighted vs. simple averages |
| 09 | Which loans failed covenants at the last test, and by how much? | Direction-aware cushion math |
| 10 | What matures in the next eight quarters? | Date bucketing, pivot by facility type |
| 11 | Which pass-rated borrowers had a sharp drop in DSCR? | `LAG()` on financials, early warning filter |
| 12 | What are annual net charge-offs? | Ratio of sums across snapshots |
| 13 | What is 12-month expected loss on the current book? | Joins model output, LGD from loss history, EAD with undrawn lines |

## PD model summary

| Step | Approach |
|---|---|
| Target | Default (90+ DPD or nonaccrual) within 12 months of the statement date |
| Samples | Development FY2022 to FY2023 (40 defaults); out-of-time FY2024 (31 defaults) |
| Variables kept | DSCR, loan to value (CRE), industry risk tier |
| Selection | IV of at least 0.02, monotonic WoE, positive coefficients, backward elimination at p of 0.20 |
| Performance | AUC 0.84 development, 0.77 out of time; KS 0.42 out of time |
| Output | PD, score (600 = 50:1 odds, 20 points to double), and grade on the bank's 9-point master scale |

## Findings worth discussing in an interview

1. **The model beats the officers' grades, but that doesn't make it a replacement.** It is better used as a challenger and early-warning tool, because officers see qualitative information the statements don't.
2. **Ranking well is not the same as being calibrated.** The model's PDs are too spread out, so they need recalibration before they drive reserves or pricing.
3. **A modeling trap caught along the way.** Giving C&I-only ratios an "N/A" bin for CRE borrowers turned them into a hidden sector flag. Binning within sector with a neutral WoE fixed it.
4. **Office CRE dominates loss.** It is 9% of exposure but 46% of expected loss, which is a concentration conversation for credit committee.

## Run it yourself

```bash
pip install pandas numpy scikit-learn statsmodels matplotlib jupyter
cd data && python generate_data.py          # rebuilds the database (seeded, reproducible)
cd ../notebooks && jupyter notebook PD_Model.ipynb
```
